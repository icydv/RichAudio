# Installed vehicle to decoded-bank registry

The shared registry now connects the actual selected vehicle audio graph to an already verified PCM bank. `loadInstalledStockRegistry` requires a digest-pinned catalogue and matching parser provenance. It compares all six AWC stream IDs, payload digests, exact container paths, native frame counts, sample rates and codecs. Recovered display names, vehicle class and approximate bank similarity never select a source. Bank objects must come from the verified asset loader.

Callers must supply an unsigned model hash and explicitly choose `player` or `npc`. The registry can construct the existing `StockVehicleSource` for an exact available mapping; it rejects unsupported, ambiguous and missing mappings. It does not replace a missing NPC definition with player audio. Existing source options remain explicit; this registry does not change source mixing or the accepted10× exterior pressure profile.

The actual935-model catalogue resolves nine player-context model bindings to the four existing decoded banks: Bati/Bati2/Thrust share the exact Bati assets; Schafter3/4/5/6 share the exact Schafter assets; Lectro and Prototipo retain their respective banks. These shared definitions are installed-graph evidence, not manually authored substitute-bank aliases.695 further player-context definitions require decoded banks and231 fail the verified six-state graph contract. All935 NPC definitions remain unsupported by that contract. Binding availability does not establish live vehicle support, placement, native suppression, mix calibration or perceptual acceptance for those models.

Five focused tests passed with the genuine local assets, including full10.3-second source waveform hashes for the four original banks. The registry check additionally exercises shared graphs, explicit context, wrong payload/path/rate/frame count/codec/ID, ambiguous channels, missing states, duplicate model hashes, parser mismatch, forged bank objects and ambiguous decoded banks. Fixtures are temporary and local. No audition matrix, full-map export, PCM extraction, game launch or endpoint access ran.

Sanitized measurements: `evidence/installed-stock-registry-01.json`. The next source integration work must establish NPC state semantics and support additional genuine banks; this registry intentionally does not invent absent deceleration recordings.
