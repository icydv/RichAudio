# My smallest CodeWalker.Core API request

This is prepared text for my involvement, **not a sent message**. My existing permission to use the API and bundle unmodified Core with necessary dependencies remains accepted. I am not restarting that permission discussion or claiming rights to modified Core, proprietary bootstrap material or keys.

> Could an unmodified Enhanced-capable Core expose two public, headless entrypoints: (1) a directory reader over a caller-owned bounded stream, with the original logical archive name and declared full archive length supplied separately, explicit limits/cancellation, and no path opening or recursive discovery; and (2) explicit-memory initialization through a legitimately supplied capability, with no implicit executable/resource/file loading, scoped state restoration/cleanup and an identified Enhanced-compatible input contract? Could you identify an authenticated Core-only artifact and its exact required dependencies/notices for those APIs, excluding proprietary bootstrap payloads?

For the directory reader, the bounded stream length must not silently replace the original archive length used in encryption selection. Core must document whether it needs the leaf filename or another logical name, and exactly which byte ranges it consumes. A newly required range can return a bounded request or fail; it cannot open another archive or enumerate the installation. The existing public `ScanStructure` path does not establish that contract.

For initialization, a public byte-array/capability interface must identify which inputs are required and who supplies them legitimately. Opaque bootstrap data, AES and expanded NG state are different contracts. Gen9 layout selection alone supplies none of them. A supplied AES argument to the existing path loader does not remove its bootstrap-resource dependency. A scoped context must define serialized use/restoration of Core's process-global crypto/Gen9 state; cancellation must not publish partially initialized state. This question does not request any key or proprietary payload to be sent or redistributed.
