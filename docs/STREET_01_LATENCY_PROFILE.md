# STREET-01 explicit latency selection

My normal Bati candidate can explicitly select the new immutable `street-01` profile. It reuses the existing 75 ms observation-history setting, eight-block cold startup, six-block prepared-source credit window and eight-slot physical ring. The 48 kHz / 512-frame block, source leases, extrapolation limits, submission path and starvation guards are unchanged. The 75 ms setting is one control-history component; it is not total audible latency.

The new name separates normal product selection from the sealed `low-latency-01` demonstration contract. That older selection still requires its existing Bati-player demonstration package. `street-01` accepts a normal package containing exactly the Bati player bank and, optionally, its separately verified NPC mapping. It requires independent camera/source continuity. An absent profile retains the previous baseline; no existing manifest or installed package was automatically changed.

Codex compared the actual Windows profile with the JavaScript profile, exercised the production credit controller and native PCM ring, and retained 34,304 exact marker frames. Cold credits stayed at eight until the prepared-source gate, exactly two credits were retired once, steady occupancy remained six, and a deliberate exhausted-ring failure remained fatal. The [private ring receipt](../.local/street01/latency-tests/48847c19-c2da-4671-aeff-78e6ac2b7054/validation.json) contains the unchanged baseline and sealed profile alongside the new selection.

The existing source/grain pipeline produced identical Float32 PCM under `street-01` and the original 75 ms policy through authored camera changes, dismount, an observed engine stop, resumed running and original lease expiry. A separate [actual main-worker receipt](../.local/street01/worker-tests/e71acf63-9299-421d-a9b7-ce31a7db4a37/street-profile/worker-receipt.json) used the production persisted C# settings command, original-only source files and the real Node worker. It retained one running Bati source after the authored dismount, with local rider airflow released and spatial exterior airflow continuing. Invalid normal selections and attempts to apply the sealed profile without its demonstration contract were rejected before source loading.

This is implemented and offline verified. The actual 90-block worker fixture retained one processing deadline miss and an 11.7267 ms maximum. That failure remains visible; the new selection does not establish complete performance acceptance, speaker latency or live responsiveness. An integrated candidate still needs the separately approved GTA demonstration and my listening assessment.
