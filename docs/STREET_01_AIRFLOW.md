# STREET-01 airflow integration

I now have two separate procedural airflow layers in the main `StockGameplay` path. My Bati's exterior rush is a separate source in the existing `CausalSimulation` / `StreamingRenderer` pipeline. It receives the same finite-surface visibility, reflection delays, arrival directions, distance losses and single propagation Doppler calculation as the other sources. Rider turbulence enters the renderer as local stereo pressure, before the existing output attenuation and headroom check. It has no world reflection paths or propagation resampler.

Both layers use source velocity relative to air. The current game adapter supplies no qualified wind observation, so the integration explicitly assumes still air. Native coordinates retain the existing declared one-unit-per-metre assumption; the authored metre fixtures do not establish GTA's physical scale. Player-bank selection alone cannot enable the local layer: both an observed riding relationship and an observed attached vehicle camera must be present. Detached roadside listening retains the spatial exterior source. Coasting with the engine stopped can still produce airflow; stationary sources do not produce wind from camera rotation.

My selected engine/exhaust pressure balance is preserved. `airflowEnabled` defaults to `false`; `airflowLevel` defaults to `0.35` and is bounded to `0..1`. Noise, filters and source identities survive blocks, camera changes and disabled periods. Detachment releases local turbulence over exactly 960 frames. Source/listener loss releases only the last retained local pressure over at most 960 frames, without inventing new motion or wind observations. Existing spatial arrivals retain the renderer's normal release behavior. No audio block, producer queue or fixed latency setting was enlarged.

The rider speed cases isolate air-relative emission with fixed source/listener separation. Roadside pass observations contain the corresponding source motion. These files use an original analytic engine bank, not my retained proprietary Bati recordings.
