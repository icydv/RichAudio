## Boundary and observation classification

`IGameObservationSource` exposes immutable-in-practice plain observation values to `SharedFrameSampler`. The SHVDNE implementation acquires and discards GTA wrappers within each callback. The sampler retains only integer discovery keys and copied numbers. Wire source IDs are independently allocated session-local strings, with generation and monotonic sample time; no GTA wrapper or memory address enters long-lived acoustic state.

In the table, **public native, source verified** means the signature/hash or matching public wrapper was checked in the pinned upstream source and the call compiles against the real API. It does not mean runtime dispatch was observed. **Memory-layout dependent** is a separate category even where a public C# property exists. The complete pinned [native hash declarations](https://github.com/Chiheb-Bacha/ScriptHookVDotNetEnhanced/blob/d756d479337a677cce9853b0cce63471c1fc7b7c/source/scripting_v3/GTA.Native/NativeHashes.cs), [vehicle wrapper](https://github.com/Chiheb-Bacha/ScriptHookVDotNetEnhanced/blob/d756d479337a677cce9853b0cce63471c1fc7b7c/source/scripting_v3/GTA/Entities/Vehicles/Vehicle.cs), and [entity wrapper](https://github.com/Chiheb-Bacha/ScriptHookVDotNetEnhanced/blob/d756d479337a677cce9853b0cce63471c1fc7b7c/source/scripting_v3/GTA/Entities/Entity.cs) are the reference surface.

The optional memory-backed getters are diagnostic admission, not automatic qualification. Upstream `CurrentRPM`, gear and several other getters return zero when an address or offset is absent. A plausible zero or an in-range value therefore cannot establish exact-build validity. My release path cannot claim vehicle synthesis parity until a separately approved exact-build observation run establishes that the chosen operating-point path works, including zero/idle, acceleration, deceleration and independent NPC cases. The default smoke configuration sends listener state and records raw vehicle diagnostics while withholding unproven operating points.

The explicit Enhanced-native option is independent of SHVDNE's optional property offsets. Its declaration was rechecked in [NativeDB Gen9 revision `424fb51b089049a9fbcebcc641500b1d44d255b4`](https://github.com/alloc8or/gta5-nativedb-data/blob/424fb51b089049a9fbcebcc641500b1d44d255b4/natives_gen9.json); the retained JSON SHA-256 is `c58064f5f3b89a0acd58fe3a3497e817311e965b0595776402886949249c5a5e`. The existing `src/telemetry/ShvHandoff/NativeIds.h` uses the same original hash. The preserved [upstream telemetry report](UPSTREAM_RPH_ENGINE_TELEMETRY_REPORT.md) records 1,869 independently observed SHV results on the same Enhanced executable file version, varying from approximately 0.2 to 1.0, with incomplete controlled phase labels. Those observations support this candidate route; they do not establish SHVDNE invocation, physical RPM, exact semantic calibration or full-state/NPC qualification. This migration copies no historical authorization and performs no new call in GTA.

## Identity, freshness and bounded work

The sampler prioritizes the player, checks up to eight additional discovery candidates each capture, and retains at most the configured maximum (never above the existing wire maximum of 32). Existing NPC lifetimes receive the RPH path's 1.3 distance hysteresis; full handle order breaks ties deterministically. NPCs beyond 600 native units retire before the RPM filter. Full fleets continue admitting nearer newly discovered NPCs. The wrapper's pool enumeration runs at most once per second, but its internal cost is not preemptible: a measured overrun withholds vehicle publication, and the exact-build smoke must measure that cost.

Identity validity uses full public script handles, model/type/existence before and after getters, and a separate latest valid lifetime-observation time. Invalidity, model change, reversed observation time or a gap above 250 ms retires that identity. Missing RPM does not refresh accepted source chronology; if raw lifetime observations remain continuous, later valid RPM starts a new source generation after a source gap. Teleports similarly advance source generation. Mounting/dismounting changes rider attachment while preserving the lifetime's original acoustic-bank context.

**Unobservable reuse remains a limit:** if the runtime recycles the identical full integer handle and model between observations without an observable invalidity, no documented read-only identity field used here distinguishes the old and new instances. Generation wrap is one possible form of this ambiguity. The sampler does not claim pointer-free perfect identity across that event. It retires after missed validity/freshness and never transfers native audio ownership, but exact-handle ABA behavior remains a live admission concern. The isolated disposable probe has its own stronger script-owned identity controls; those controls do not authorize decorating arbitrary world vehicles.

## Execution context

The selected [Script implementation](https://github.com/Chiheb-Bacha/ScriptHookVDotNetEnhanced/blob/d756d479337a677cce9853b0cce63471c1fc7b7c/source/core/Script.cs) runs the normal dedicated script loop, dispatches queued keyboard handlers, calls `Tick`, then yields through its interval scheduling. This is not RPH's fiber model. `Function.Call` in the [API3 invocation implementation](https://github.com/Chiheb-Bacha/ScriptHookVDotNetEnhanced/blob/d756d479337a677cce9853b0cce63471c1fc7b7c/source/scripting_v3/GTA.Native/Native.cs) routes through [NativeFunc](https://github.com/Chiheb-Bacha/ScriptHookVDotNetEnhanced/blob/d756d479337a677cce9853b0cce63471c1fc7b7c/source/core/NativeFunc.cs). The [ScriptDomain implementation](https://github.com/Chiheb-Bacha/ScriptHookVDotNetEnhanced/blob/d756d479337a677cce9853b0cce63471c1fc7b7c/source/core/ScriptDomain.cs) applies game-thread TLS around native tasks. It does not mean the callback itself is running on the main game thread. RichAudio uses only these public invocation paths, not private TLS operations or unmanaged hooks.

`ShvdneGameSource` binds its callback-thread guard on first use. Game reads remain in `Tick` or its synchronous callees; workers receive only copied values. There is no worker-side native invocation, audio rendering, filesystem preparation or pipe connection in this provider. Side observations are acquired once per callback and retain their original times. The host and latest-state publisher own background work.

Upstream `Script.Abort` documents races and may invoke `Aborted` from the script-domain thread instead of the script thread. Consequently abort cleanup must signal cancellation and release non-game resources; it cannot assume a supported native-delete context. Normal probe cleanup uses an explicit command processed on the script callback. Abnormal abort does not prove independent restoration, and Gate A recovery criteria remain unchanged.

## Offline evidence and remaining coverage

`tools/Test-ShvdneObservations.ps1` compiles the actual framework-independent boundary plus verbatim pure observation/tracker classes extracted from the unchanged RPH camera source. It also compiles the actual `ShvdneGameSource` against explicitly authored fake API responses. **Thirty-one cases and 124 assertions passed**: 19 boundary cases/100 assertions and 12 provider cases/24 assertions. The fixture compares serialized listener outputs for motion, cuts, cached samples, pause, invalid pose/time, orientation and clock transitions; it exercises source isolation, lifetime retirement, model changes, missing/invalid RPM, chronology, immutable vectors, full-fleet admission, range retirement, restart sessions and unchanged wire round trips. Provider cases cover actual default-versus-opt-in wrapper behavior, exact Enhanced RPM hash/handle dispatch, no fallback or retry after a native exception, matrix/camera/interior argument construction, pre/post model and driver checks, invalid handles, online refusal and cross-thread rejection before any fake native dispatch. Its JSON receipt retains source and binary hashes. Re-run after source changes and use the latest receipt for final counts.

The production SHVDNE provider also compiles against the authentic API3 binary with warnings treated as errors. This checks public symbol/signature compatibility, not runtime dispatch, pool validity or acceptable callback cost. These fixtures do not measure GTA rendering, audio fidelity, acoustic scheduling, frame rate, endpoint latency or real world coverage. Existing PCM/acoustic regression suites remain the authority for unchanged engine behavior.

Remaining observation gaps are exact `.16` runtime admission, memory-backed operating-point/gear/drivetrain qualification, the unobservable same-handle/model reuse case, individual wheel/contact/suspension/material observations, and proof that callback/pool-enumeration costs meet gameplay requirements. Native profile resolution, selective suppression and controller-independent restoration remain separate unqualified Gate A capabilities.
