# ACOUSTIC-WORLD-03: my next real-resource evidence boundary

I have not authorised an installed-game scan in this increment. My next useful resource experiment is a **read-only, explicitly selected building subset**, with no GTA/RPH launch, endpoint, recording, deployment or native audio change. This is a proposed scope, not an executable candidate or permission to inspect the installation now.

## Smallest useful input

The preferred input is one privately retained, explicitly selected compressed YMAP, its required YTYP and one corresponding static-triangle YBN, with their original logical mount paths. The subset must be within the current 16 MiB per-resource / 32 MiB total limits and the existing finite-surface budgets. It must include enough original metadata to establish which enabled mount wins and why the YBN belongs to that placement. Unselected resources remain unknown; a parser success cannot certify an empty street or an effective installation.

An authorised private export avoids opening installed archives. If obtaining it instead requires installation access, the final proposal must list the **exact archive files and logical members**, including only the base/override and mount metadata needed for this subset. It may not grant recursive discovery of the entire game, unrelated audio, credentials, archive modification or bulk extraction. If those exact paths cannot yet be named, the next approval must cover a separate bounded metadata inventory first; this document does not silently broaden access to find them.

## Required preparation before any approval is actionable

Codex must prepare a new private, independently reviewed candidate containing:

1. The authoritative input manifest: exact private root, explicit resource/archive/member allowlist, byte/count limits, read-only operations, output root and no-follow path rules. No recursive installation enumeration or automatic fallback selection.
2. Hash-pinned tool/source/runtime/dependency closure and the pinned public parser profile. The Gen9 selector is explicit; RSC7 version bytes alone cannot select Enhanced semantics.
3. An external parser process contract with independent wall-time, memory/output bounds, cancellation and verified process exit. The current in-process authored fixture proof is insufficient for arbitrary private/hostile resources. No parsing on a game fiber, producer/render thread or audio callback.
4. A fresh proposal and review receipt binding the exact commands and paths, an unconsumed attempt identity and a no-retry rule. The final proposal must be reviewed before I approve access. No old endpoint candidate or approval can be reused.

## Evidence and stop conditions

The experiment would retain private input SHA-256/lengths, effective mount/override evidence, parser diagnostics, original transforms, collision ownership links, coordinate/scale evidence, supported and rejected item counts, finite tile bounds, unknown coverage and cache invalidation inputs. Proprietary bytes and private paths would not enter GitHub.

Missing dependencies, ambiguous mount order, unresolved placement/collision links, unsupported winning resources, unknown activation, unqualified coordinates, oversized geometry or parser supervision failure must stop qualification. No fallback to a lower-priority map, inferred collision rectangle, guessed material or fabricated empty volume is allowed. Diagnostic decoding may still be retained as unqualified evidence, with no gameplay activation.

Even a successful read-only resource experiment would establish a bounded static subset, not a loaded runtime scene. Exact-target scale, activation, interiors and dynamic objects need their own evidence. The current importer deliberately returns `unqualified-installation-evidence` for real-resource authority until those contracts exist.
