# Capture bounds for the preserve controls

I keep the active experiment at 600 seconds from the single F5 request. Recording may include up to 60 seconds before F5 and up to 120 seconds after that active allowance: at most 780 seconds in total. The actual bound is also checked against `activeStart + 600 + 120`, so shorter pre-roll does not grant extra closure time. Exceeding a bound means retaining the recording and reporting an analysis refusal; it never calls for forced exit or more experimental time.

`Extract-Capture05.py` extracts an explicitly declared ten-second window. `--active-start` is the fixed F5 journal timestamp minus the OBS recording-start timestamp, recorded in the new scope's timing receipt. Every requested window must fall within that active interval. The tool never chooses or moves a cut. Nonzero first audio PTS is refused because the existing timestamp validator and sample indexing require the recording origin to match audio origin.

Both modes preserve an immutable source prefix, check source bytes and identity, reject decoder-reported corruption, and validate every available decoded timestamp with the unchanged `CaptureTimeline03C` policy. `--finalized` additionally requires a finalized duration, stable whole-file identity and stream coverage through the container tail. The 512 MiB limit, 48 kHz stereo format, bounded decoded sample/frame counts, and video dimensions no greater than 1920×1080 constrain decoding. A growing prefix is never represented as a finalized recording. Context and acoustic attribution still require separate review.

The command requires `source target --start SECONDS --duration 10 --active-start F5_OFFSET --run-root DIRECTORY --dependencies MANIFEST --dependencies-sha256 SHA256`, plus `--finalized` after normal recording closure. Bind these paths, manifest digest and timing offset in the candidate scope; use the retained isolated Python invocation. No alternate dependency download or fixture bypass exists.

`Test-Capture05.py --retained-repo DIRECTORY --out DIRECTORY` reuses authored media and the actual 624.100-second recording. It checks the new bounds, malformed media, gaps, incomplete intervals, source changes, shifted audio origin and oversized video headers. The actual-recording regression compares the preserve PCM and the complete AV timestamp arrays. It does not rerun a live experiment or change the historical candidate-04 rejection.
